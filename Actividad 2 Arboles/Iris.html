1. Introducción

El algoritmo Naive Bayes es un clasificador probabilístico fundamental basado en el Teorema de Bayes. Aunque asume independencia condicional entre los predictores (de ahí el término "ingenuo"), resulta ser extremadamente rápido, escalable y eficaz para múltiples problemas de clasificación estadística y minería de datos.

2. Exploración Visual de los Datos

Antes de entrenar el modelo, es una buena práctica analizar la distribución de nuestras variables. Utilizaremos ggplot2 para visualizar el solapamiento entre las diferentes especies según las dimensiones de sus pétalos.

# Cargar librerías necesarias
library(ggplot2)
library(caret)
library(e1071)

data(iris)

# Gráfico de dispersión: Longitud vs Ancho del Pétalo
ggplot(iris, aes(x = Petal.Length, y = Petal.Width, color = Species)) +
  geom_point(size = 3, alpha = 0.7) +
  theme_minimal() +
  labs(title = "Distribución de Especies de Iris (Pétalo)",
       x = "Longitud del Pétalo",
       y = "Ancho del Pétalo")

Nota: Visualmente podemos notar que la especie Setosa es linealmente separable, mientras que Versicolor y Virginica presentan una ligera región de solapamiento espacial.

3. Carga de Datos y Entrenamiento del Modelo

Dividimos el dataset en conjuntos de entrenamiento (80%) y prueba (20%).

set.seed(123)

# División de los datos
indices <- sample(1:nrow(iris), 0.8 * nrow(iris))
train <- iris[indices, ]
test <- iris[-indices, ]

# Entrenamiento del modelo Naive Bayes
modelo_nb <- naiveBayes(Species ~ ., data = train)
print(modelo_nb)

4. Validación Cruzada (10-Fold Cross-Validation)

Para asegurar que nuestro modelo generaliza correctamente y evitar el sobreajuste (overfitting), aplicamos validación cruzada con 10 pliegues utilizando la librería caret.

set.seed(123)
# Configurar el control del entrenamiento
train_control <- trainControl(method = "cv", number = 10)

# Entrenar el modelo con CV
modelo_cv <- train(Species ~ ., data = iris, 
                   method = "naive_bayes", 
                   trControl = train_control)

print(modelo_cv)

5. Predicción y Métricas de Evaluación

Evaluamos el rendimiento del modelo inicial sobre nuestro set de pruebas (20%) extrayendo la matriz de confusión completa, lo que nos dará la exactitud, sensibilidad y especificidad.

# Generar predicciones
predicciones <- predict(modelo_nb, test)

# Matriz de Confusión detallada
matriz_confusion <- confusionMatrix(predicciones, test$Species)
print(matriz_confusion)

# Extraer solo la precisión global
precision <- matriz_confusion$overall['Accuracy']
cat("\nPrecisión global del modelo en Testing:", round(precision * 100, 2), "%\n")

6. Simulación con Matriz de 20 Muestras Aleatorias

Extraemos un subconjunto completamente aleatorio para realizar un test rápido del comportamiento del algoritmo.

set.seed(456)
indices20 <- sample(1:nrow(iris), 20)
m20 <- iris[indices20, ]

# Predicción sobre las 20 muestras
p20 <- predict(modelo_nb, m20)

# Comparación rápida
resultados_20 <- data.frame(Real = m20$Species, Prediccion = p20)
table(Prediccion = p20, Real = m20$Species)

7. Conclusión

El modelo Naive Bayes demostró un rendimiento sobresaliente, manteniendo un alto Accuracy incluso al ser sometido a validación cruzada. El ligero margen de error, tal como lo corroboró el análisis visual con ggplot2, se atribuye exclusivamente al solapamiento natural entre las métricas de versicolor y virginica. La implementación de estas metodologías de evaluación (como CV y Matrices de Confusión avanzadas) resulta vital en la construcción de sistemas expertos y arquitecturas de inteligencia artificial fiables.
